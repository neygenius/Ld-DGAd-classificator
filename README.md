### Экспериментальные данные по теме использования NLP для детектирования DGA доменов

---

1. `models.ipynb` - Основной ноутбук посвященный исследованию features моделей, обновленная версия экспериментов с НИРС: дополнительная работа на данными, 
разделение на In-distribution, Out-of-distribution, больше метрик, XGBoost, MLP, обновленная система оценивания качества обучения и др.
2. `e2e_models.ipynb` - Новый ноутбук посвященный исследованию DeepLearning моделей: CharCNN, CharBERT, [DomURLs_Bert](https://huggingface.co/amahdaouy/DomURLs_BERT) для референса + все метрики из основного ноутбука и др.
3. `models_optimization.ipynb` - Новый ноутбук посвященный теме оптимизации features моделей: оценка значимости признаков, переобучение на меньшем объеме фичей, "перебор" гиперпараметров, пересчет метрик и др.
